Screen boundary

The device
disappears.

When media occupies a contained display plane, the boundary must be felt without competing with content. The original project’s dark iPhone frame becomes a direct exercise in edge visibility, contrast, and landscape viewing.

01Physical frame anchors moving content.
02Dark surrounding space protects visual attention.
03Landscape mode changes the hierarchy of the interface.

Project provenance

A map can
be evidence.

The original Canada map is retained as a visual record of the project’s regional scope. It is no longer a carrier or store finder: it becomes a simple provenance artefact showing that interface design is always situated in a wider geography.

By separating product object, technical specimen, movement, and context into four routes, the system replaces the old single-direction sales funnel with a portfolio narrative that allows inspection from multiple entry points.

Closing frame

Signal / Object turns an existing iPhone product exercise into a deliberately authored system of materials, measurements, motion, and context—using the actual images and videos that were already part of the project.
